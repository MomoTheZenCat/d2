# 第三幕庫拉斯特下水道：樓梯和克林姆的心臟在哪？

方向一律是**螢幕上的方向**（斜角視角）。資料來自 D2MOO（開源重建的《暗黑破壞神 II》1.10 地圖程式）、D2R 的地圖檔，以及 60,000 場模擬。**還沒有在遊戲裡實測。**

---

## 1. 下水道第一層：固定的環，四個入口

這一層一開始一定是一個 **16 間房的環**（5×5 的正方形，中間是空的）。環的四個角就是四個入口：

```
                                                 庫拉斯特上層
                                                      /\
                                                    /    \
                                                  /        \
                                                /            \
                                              /                \
                                            /                    \
                                          /                        \
                                        /                            \
                                      /                                \
                                    /                                    \
                    庫拉斯特市集       <         下水道第一層（起始環）                   >  庫拉斯特上層
                                    \                                    /
                                      \                                /
                                        \                            /
                                          \                        /
                                            \                    /
                                              \                /
                                                \            /
                                                  \        /
                                                    \    /
                                                      \/
                                                 庫拉斯特市集
```

- **庫拉斯特市集**從**左邊**或**下方**的角進來（有兩個活板門）。
- **庫拉斯特上層**從**上方**或**右邊**的角進來。
- 迷宮其餘的部分（總共 32 間房，每間 12×12 格）從環往外隨機長出去。

### 往第二層的樓梯（有拉桿的那間房）
- **位置沒有規則。** 出現在地圖四塊的機率差不多（23–24%），離每個入口也差不多遠（**平均 6 間房**）。
- 通常**在起始環的外面（92%）**，在往外長出去的那部分。所以不要在環上繞，要往環外面找。
- 它的朝向是迷宮蓋好之後擲的（各 25%）。那間沒什麼用的安慰獎箱子房，朝向是它順時針轉 90°。

### 前面的地圖幫不上忙
環是固定的，樓梯那一擲之前的迷宮亂數次數不固定，所以第一到第三幕的任何地圖都對不上它（見 [act5-caves.zh-TW.md](act5-caves.zh-TW.md) 的「同一個位置的亂數」規則）。

## 2. 下水道第二層：固定地圖

第二層是**一張固定的地圖**（`SewerTreasure1.ds1`，18×22 格），每一場都一樣：

```
                                                      /\
                                                    /    \
                                                  /        \
                                                /            \
                                              /                \
                   進來的地方（邊的中間）             /                    \  心臟的箱子（邊的中間）
                                          /                        \
                                        /                            \
                                      /                                \
                                    /                                    \
                                  <        下水道第二層（固定地圖）                   >
                                    \                                    /
                                      \                                /
                                        \                            /
                                          \                        /
                                            \                    /
                                              \                /
                                                \            /
                                                  \        /
                                                    \    /
                                                      \/
```

- 你從**左上邊的中間**進來。
- **克林姆的心臟的箱子**在**右上邊的中間附近**：在螢幕上就是**你的正右方，大約 11 格**。永遠在那裡。

## 3. 原始碼和資料

| 內容 | 位置 |
|---|---|
| 16 間房的環、4 個角的入口、長到 32 間 | `D2Common/src/Drlg/DrlgMaze.cpp` → `LVLTYPE_ACT3_SEWER`（`DRLGMAZE_InitBasicMazeLayout(pLevel, 5)`，4 次 `DRLGMAZE_ReplaceRoomPreset` 換成 `SEWER_PREV_*`） |
| 樓梯（排水口）朝向 `R & 3`，箱子房 +90° | `DRLGMAZE_PlaceAct3SewerStuff` |
| 哪個角通到哪裡 | `Act3/Sewer/Sewer{NE,NW,SE,SW}_Warp.ds1` 的傳送格 → `Levels.txt` 下水道第一層 `Vis0–3`（庫拉斯特市集 ×2、庫拉斯特上層 ×2）；排水口房間有物件 100 `BeneathTheCityLever` ＋ 101 `BeneathTheCityStairs` |
| 第二層是固定的 | `Levels.txt` 下水道第二層＝預設地圖，18×22；`LvlPrest`「Act 3 - Sewer Treasure X」→ `SewerTreasure1.ds1`，物件 113 `KhalimHeartChest` |
| 房間數／打通機率 | `LvlMaze.txt`：32 間、12×12、merge 800 |
