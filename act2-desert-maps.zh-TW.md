# 第二幕沙漠地圖：每一關出口的機率

每張圖是**目前所在的關卡**。8 個格子 d0–d7 標的是**下一關出現在那裡的機率**；`X` 代表不可能（被前面的關卡擋住）。上一關直接標在**它實際所在的格子**（`dX = 關卡名`）。

**怎麼查：** 先看上一關接在哪一格（d0–d7），找到對應的那張圖。

格子位置：右上邊 = d4（靠上）、d5（靠右）；右下邊 = d6（靠右）、d7（靠下）；左下邊 = d0（靠左）、d1（靠下）；左上邊 = d2（靠上）、d3（靠左）。

高機率的格子（25–50%）都是**被擋住的格子順時針的下一格**：擲到被擋住的格子時，遊戲會往下一格擠。
