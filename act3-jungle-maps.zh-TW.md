# 第三幕叢林地圖：蜘蛛森林、大沼澤、剝皮叢林

每張叢林地圖都是 **2 × 6 格**。列從 **1（南端，靠庫拉斯特港口）到 6（北端）**；每一列的 **a** 是左上那格，**b** 是右下那格。

**通往其他叢林的出口只會在 6a、5a、5b、3a、3b**。這是程式寫死的（`DRLG_GenerateJunglesAttachPoints`），不是隨機。**6b 永遠不會是叢林出口。** 從上一塊叢林進來的入口一定在**第 1 列**（1a 或 1b）。

| 出口格 | 下一塊叢林在哪 |
|---|---|
| 6a | 正北 |
| 5a／5b | 西／東，往北偏 2/3 |
| 3a／3b | 西／東，往北偏 1/3 |

## 1. 蜘蛛森林

```
  Spider Forest: chance of a jungle exit at each tile

                                                                 /\
                                                               /    \
                                                             /        \
                                                           /\  6a 31%  /\
                                                         /    \      /    \       (north)
                                                       /        \  /        \
                                                     /\  5a 28%  /\ 6b never /
                                                   /    \      /    \      /
                                                 /        \  /        \  /
                                               /\    4a    /\  5b 28%  /
                                             /    \      /    \      /
                                           /        \  /        \  /
                                         /\  3a 28%  /\    4b    /
                                       /    \      /    \      /
                                     /        \  /        \  /
                                   /\    2a    /\  3b 28%  /
                                 /    \      /    \      /
                               /        \  /        \  /
                              \    1a    /\    2b    /
                                \      /    \      /
  from Kurast Docks =>            \  /        \  /
                                    \    1b    /
                                      \      /
                                        \  /
```

- 每格的百分比是**那一格有叢林出口的機率**。蜘蛛森林有 1 個或 2 個叢林出口，所以各格加起來約 **141%**（1 × 58.9% + 2 × 41.1%），不是 100%。
- **1 個出口（58.9%）：** 通往大沼澤，一定要穿過去。
- **2 個出口（41.1%）：** **能跳過大沼澤**，**比較北**的出口通往剝皮叢林（**6a > 5 > 3**）。兩個出口在同一列時（3a + 3b，或 5a + 5b）判斷不了。

**蜘蛛森林只有 1 個出口時（58.9%），出口在哪：**

| 出口 | 機率 |
|---|---|
| 5a | 21.2% |
| 5b | 21.2% |
| 3a | 19.4% |
| 3b | 19.4% |
| 6a | 18.8% |

**有 2 個出口時（41.1%），是哪兩個：**

| 組合 | 機率 | 通往剝皮叢林的出口 |
|---|---|---|
| 3a + 3b | 13.9% | 判斷不了 |
| 3a + 5b | 13.1% | 5b |
| 3b + 5a | 13.1% | 5a |
| 3a + 6a | 12.4% | 6a |
| 3b + 6a | 12.4% | 6a |
| 5a + 5b | 12.2% | 判斷不了 |
| 5a + 6a | 11.4% | 6a |
| 5b + 6a | 11.4% | 6a |

## 2. 大沼澤

```
  Great Marsh: entrance (row 1) and exit to Flayer Jungle

                                                                 /\
                                                               /    \
                                                             /        \
                                                           /\  6a 13%  /\
                                                         /    \      /    \       dead end (no exit)
                                                       /        \  /        \
                                                     /\  5a 13%  /\ 6b never /
                                                   /    \      /    \      /
                                                 /        \  /        \  /
                                               /\    4a    /\  5b 13%  /
                                             /    \      /    \      /
                                           /        \  /        \  /
                                         /\  3a 10%  /\    4b    /
                                       /    \      /    \      /
                                     /        \  /        \  /
                                   /\    2a    /\  3b 10%  /
                                 /    \      /    \      /
                               /        \  /        \  /
                              \  1a 56%  /\    2b    /
                                \      /    \      /
entrance (1a or 1b) =>            \  /        \  /
                                    \  1b 44%  /
                                      \      /
                                        \  /
```

- **入口：** 1a 56%、1b 44%。1b 代表大沼澤接在上一塊的**西邊**；1a 代表接在北邊或東邊。
- **死路 41%：** 如果蜘蛛森林有 2 個出口，大沼澤就**沒有**通往剝皮叢林的出口，要回頭。
- **否則它剛好有一個**通往剝皮叢林的出口，在 6a／5a／5b／3a／3b（機率如圖），不會是 6b。

## 計算方式
照程式建叢林的方式，把所有可能的叢林排法全部列舉（D2MOO `DrlgOutPlace.cpp` 的 `DRLG_GenerateJungles`、`sub_6FD83970`、`DRLG_GenerateJunglesAttachPoints`）。3 塊叢林各 64×192，5 種接法全部往北。兩塊一樣高時，哪一塊變成大沼澤不固定，這種情況各算 50%。

來源：D2MOO，也就是開源重建的《暗黑破壞神 II》1.10 程式碼。另見 `flayer-skip.zh-TW.md`。
