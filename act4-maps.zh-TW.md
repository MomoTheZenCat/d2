# 第四幕地圖：出口方向機率

方向一律是**螢幕上的方向**（斜角視角）。資料來自模擬 D2MOO（開源重建的《暗黑破壞神 II》1.10 地圖程式），使用真正的亂數產生器，共 600,000 場遊戲。**還沒有在遊戲裡實測。**

---

## 1. 混沌界要塞 → 外圍荒原

**永遠在右下。** 唯一隨機的是一個小位移（往上或往下 8 格），而且跟冰冷之原的方向用的是同一個亂數。

## 2. 外圍荒原 → 絕望平原

| 右上 | 右下 | 左下 | 左上 |
|---|---|---|---|
| **50%** | 25% | 25% | 不可能（要塞在那邊） |

跟冰冷之原同樣的規則：每一邊各 25%，擲到要塞那邊就往順時針的下一邊（右上）移。

## 4. 用第一幕預測絕望平原 ⭐

**每一幕都用同一個遊戲 seed 產生。** 第一幕決定鮮血荒地方向的那個亂數，就是第四幕決定絕望平原方向的那個亂數。
所以只要知道**亂石曠野和鮮血荒地在冰冷之原的哪一邊**，**75% 的遊戲可以 100% 確定絕望平原的方向**，其他情況是 50/50。

| 亂石曠野（在冰冷之原的） | 鮮血荒地（在冰冷之原的） | 絕望平原（在外圍荒原的） |
|---|---|---|
| 左下 | 左上 | 右上 50% / 左下 50% |
| 左下 | 右上 | **右上 100%** |
| 左下 | 右下 | **右下 100%** |
| 左上 | 左下 | **左下 100%** |
| 左上 | 右上 | **右上 100%** |
| 左上 | 右下 | **右下 100%** |
| 右上 | 左下 | **左下 100%** |
| 右上 | 左上 | **右上 100%** |
| 右上 | 右下 | 右下 50% / 右上 50% |
| 右下 | 左下 | 右下 50% / 左下 50% |
| 右下 | 左上 | **右上 100%** |
| 右下 | 右上 | **右上 100%** |

**簡單說：** 絕望平原跟**鮮血荒地在同一邊**，例外是：
- 鮮血荒地在**左上**的話，絕望平原在**右上**（左上是要塞那邊）。
- 鮮血荒地在**亂石曠野順時針的下一邊**的話，是鮮血荒地那邊和亂石曠野那邊各 50%（左上一樣改成右上）。

罪罰之城除了第 3 節自己的規則之外，沒辦法從第一幕預測。

## 5. 罪罰之城 → 火焰之河 → 混沌魔殿 ⭐

### 5.1 罪罰之城：找樓梯（傳送點就在旁邊）
- 往火焰之河的樓梯和**罪罰之城的傳送點在同一間房間**（`warplava.ds1`）。找到一個就找到另一個。
- 它是罪罰之城**第一個放的東西**，用的是跟第一幕遺忘之塔一樣、有偏向的格子打亂，所以偏向**地圖的上方角落**：

```
                                                      /\
                                                    /    \
                                                  /        \
                                                /            \
                                              /                \                ← 先找這裡
                                            /       上 35%        \
                                          /    \              /    \
                                        /        \          /        \
                                      /            \      /            \
                                    /                \  /                \
                                  <      左 22%         X       右 22%       >
                                    \               /    \               /
                                      \           /        \           /
                                        \       /            \       /
                                          \   /                \   /
                                            \       下 22%        /
                                              \                /
                                                \            /
                                                  \        /
                                                    \    /
                                                      \/
```

- 最可能的單一位置是**上方角落往內一格（14%）**，再來是沿著右上邊。
- 兩半：**右上半邊 56%**、**左上半邊 57%**。
- 永遠不會離地圖邊緣 8 格以內。

### 5.2 火焰之河：往右上走
火焰之河是一個小迷宮（6 間 24×24 格的房間），有三個特殊的端點：

```
                                                      /\
                                                    /    \
                                                  /        \
                                                /            \
                                              /                \
                     海法斯特的鍛造台 50%           /                    \  傳送點＋通往混沌魔殿的橋
                                          /                        \
                                        /                            \
                                      /                                \
                                    /                                    \
                                  <                火焰之河                   >
                                    \                                    /
                                      \                                /
                                        \                            /
                                          \                        /
                       入口（從罪罰之城）           \                    /  海法斯特的鍛造台 50%
                                              \                /
                                                \            /
                                                  \        /
                                                    \    /
                                                      \/
```

- **從罪罰之城下來的入口：永遠在迷宮的左下端**（最左下的那間房間，在它的左下邊接上樓梯）。
- **傳送點：永遠在右上端。** 它在往右上通進混沌魔殿的那座橋的第一間房間。
- **海法斯特的鍛造台：側邊的岔路，在左上或右下（各 50%）。** 它取代一間朝東或朝西的死路房間。

**所以：從入口一路往右上走。** 往左上或右下岔出去的路，可能是鍛造台。

**右上是死路的時候：左轉（左上）還是右轉（右下）？**

| 到傳送點的路 | 機率 |
|---|---|
| 一路往右上 | 22% |
| 第一個轉彎是**左轉**（左上） | 39% |
| 第一個轉彎是**右轉**（右下） | 39% |

- **沒有偏好**：左右一樣。
- **唯一的小線索，鍛造台：** 如果你已經看到海法斯特的鍛造台**在入口的某一邊**，往傳送點的路比較常**轉向同一邊**（**44%** vs 32%）。迷宮通常往其中一邊長，鍛造台和傳送點都會落在那邊。
- 路很短：通常 **5–6 間房**（每間 24 格），而且永遠不需要往左下走回頭路。
- **傳送點相對於入口的位置：** 通常**往右上 4 間房**（3 間 19%、4 間 54%、5 間 24%），而且通常**往旁邊偏**：

  | 往旁邊偏 | 0 間（同一直線） | 1 間 | 2 間 | 3 間以上 |
  |---|---|---|---|---|
  | 機率 | 28% | **42%** | 22% | 8% |

  所以只有 28% 在同一直線上（完全直走到底只有 22%）。最常見的是**往右上 4 間、往旁邊偏 1 間**。

**原始碼：** `D2Common/src/Drlg/DrlgMaze.cpp` → `DRLGMAZE_PlaceAct4Lava`（入口用 `DRLGMAZE_GetFreeLocationForRoomNorth`，實際上挑 Y 最大的；橋用 `DRLGMAZE_GetFreeLocationForRoomSouth`，挑 Y 最小的，再往 Y− 接 3 間；鍛造台 `R & 1` 決定 Forge W／Forge E）；D2R 地圖檔 `Act4/Diab/BridgeLava.ds1` 和 `Act4/Mesa/WarpLava.ds1` 都有物件 0 ＝ `WaypointOutsideAct4`；`Act4/Lava/ForgeE.ds1`／`ForgeW.ds1` 有物件 42 ＝ `SoulStoneForge`。罪罰之城的位置模擬了 300,000 場。

## 7. 注意事項
- **程式碼版本：** D2MOO 是 1.10 的程式碼，不是 D2R 本身的程式。第一幕和第四幕的關聯，需要兩幕用同一個 seed、而且抽亂數的順序一樣，D2MOO 裡是這樣。
- **還沒有在遊戲裡實測。** 第一幕 → 第四幕的表最容易驗證：記下亂石曠野和鮮血荒地在冰冷之原的哪一邊，再去看外圍荒原。
